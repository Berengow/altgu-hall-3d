# Холл 1 этажа ИГН АлтГУ — 3D-прогулка

Сайт с 3D-сценой холла по эскизному проекту Welle Design (2025). Можно ходить от первого лица
в браузере, на телефоне и в VR-шлеме через WebXR.

## Запуск

Нужен любой статический сервер; сборка не требуется.

```bash
python -m http.server 8765 --directory hall-3d
```

Затем открыть http://localhost:8765. Для VR-шлема сайт должен открываться по HTTPS:
подойдёт GitHub Pages, Netlify или любой хостинг статики. Достаточно залить папку `hall-3d`.

## Управление

- Компьютер: `W A S D` или стрелки — ходьба, `Shift` — быстрее. Мышь — обзор: после клика
  курсор захватывается, `Esc` отпускает. `M` — план, `H` — скрыть интерфейс.
- Телефон: левый палец — джойстик, правый — обзор.
- Кнопки внизу и клик по плану переносят в нужную зону; «Экскурсия» облетает все зоны
  с подписями из альбома (любое действие её останавливает).
- VR: кнопка в правом нижнем углу, перемещение телепортом по полу и площадкам лестниц.
- Качество переключается кнопкой справа внизу или параметром `?q=high` / `?q=low`.
  На телефонах и шлемах по умолчанию обычное: без отражений в полу и SSAO.

## Откуда геометрия

`hall-3d/plan-data.js` генерируется скриптом `tools/extract_plan.py` из векторного
PDF-альбома (масштаб 1:90), а не обрисовывается вручную:

| Лист | Что берётся |
|------|-------------|
| 10 — расстановка мебели | стены, колонны, перегородки, диваны, банкетки, столы, стулья, ограждения |
| 09 — планировочное решение | растения |
| 11 — план потолка | зоны ГКЛ, балки, существующий потолок кафе |
| 12 — план освещения | панели 600×600, линейные и подвесные светильники |
| 16 — финишные покрытия | покраска (Kent Grey, Bengal Red), штукатурка, мрамор, металл, плитка |

Объекты, которые на чертежах нарисованы только линиями (лестницы, двери, окна, витрины,
прилавок, вендинг, зеркала, ТВ, надписи), заданы вручную в конце `extract_plan.py`
по координатам листов 05, 07, 09, 10, 17 и развёрткам 19–27.

Пересборка данных после правок (нужен Python и `pip install pymupdf`):

```bash
python tools/extract_plan.py
```

Альбом ищется как `холл альбом.pdf` в корне проекта (в репозиторий он не входит) или по пути
из переменной окружения `HALL_PDF`. `tools/preview_plan.py` рисует извлечённые данные
сверху в PNG для сверки с листами. Остальные скрипты в `tools/` помогают снимать
координаты с листов.

## Освещение и материалы

Материалы физически корректные (PBR): шероховатость, металличность, карты рельефа,
сгенерированные из процедурных текстур. При загрузке сцена один раз снимает кубкарту самого
холла и освещает себя ею: отражённый свет от потолочных панелей и окон, отражения в полу,
металле и зеркалах. Прямой свет — почти вертикальный ключ с мягкими тенями от мебели
и рассеянный дневной свет от матовых окон.

## Допущения

- Высоты: потолок грильято 2,9 м, ГКЛ и кафе 2,7 м, площадки лестниц 1,54 м (лист 05).
- Лестницы П-образные, по 10 ступеней в марше. Второй марш уходит в шахту на второй этаж,
  который не моделировался.
- Мебель построена процедурно по размерам из альбома (Sigma, Mix, Фрайди, PS006.2):
  скруглённые кромки, гнутые трубы каркасов, токарные детали. Это не точные модели производителей.
- Фасадные окна — матовое непрозрачное стекло: вида на улицу нет намеренно.
- За витражом слева — условный холл музея.
